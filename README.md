# 4×4 卡诺图工具 (Karnaugh Map Tool)
*本项目由 DeepSeek-V4-Pro 模型生成。*
一个基于 Web 的 4 变量卡诺图化简工具，支持自动化简、手动圈选和 KaTeX 公式渲染。

## 功能

- **4×4 卡诺图** — 变量 Q₃Q₂Q₁Q₀，格雷码排列，每格显示取值与最小项编号
- **多标签页** — 同时打开多个卡诺图，互不干扰
- **自动化简** — 基于 Quine-McCluskey 算法求最小覆盖，结果以彩色卡诺圈显示
- **手动圈选** — 拖拽画圈，自动识别有效矩形（含边缘环绕），实时生成表达式
- **KaTeX 渲染** — 表达式以数学排版显示，NOT 为字母上横线
- **表达式编辑** — 直接编辑表达式，提供 Q₃ Q₂ Q₁ Q₀ / NOT / AND / OR / 括号 输入按钮

## 快速开始

```bash
cd k-map
npm install
npm start
```

启动后访问：

- 本机：`http://localhost:3000`
- 局域网：终端显示的 Network 地址

## 使用说明

| 操作 | 方式 |
|------|------|
| 设置取值 | 编辑模式下点击格子，循环切换 0 → 1 → X → 0 |
| 手动圈选 | 切换到圈选模式，在格子上拖拽 |
| 自动化简 | 点击「⚡ 自动化简」按钮 |
| 编辑表达式 | 直接在表达式框输入，或用下方按键插入符号 |
| 新建卡诺图 | 点击标签栏 `+` |
| 删除圈选 | 点击圈选列表中的 × |

### 表达式语法

```
Q3'·Q2 + Q1·Q0'      →  Q₃ · Q₂ + Q₁ · Q₀
Q3'·Q2'·Q1·Q0 + Q3   →  Q₃ · Q₂ · Q₁ · Q₀ + Q₃
```

- 变量：`Q3` `Q2` `Q1` `Q0`
- 取反：`'`（渲染为上横线）
- AND：`·`
- OR：`+`
- 括号：`(` `)`

## 技术栈

- 前端：HTML + CSS + JavaScript（无框架）
- 算法：Quine-McCluskey 质蕴含项 + 回溯最小覆盖
- 公式渲染：[KaTeX](https://katex.org/)
- 服务端：[Express](https://expressjs.com/)
