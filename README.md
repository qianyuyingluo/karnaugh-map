# 卡诺图化简工具 (Karnaugh Map Tool)

一个基于 Web 的 N 变量卡诺图化简工具，支持自动化简、手动圈选、KaTeX 公式渲染。

*算法：qianyuyingluo &emsp; 编程：DeepSeek-V4-Pro*

## 功能

- **N×M 卡诺图** — 2~6 变量，Gray 码排列，每格显示取值与最小项编号
- **多标签页** — 同时打开多个卡诺图，互不干扰
- **自定义变量名** — 默认 Q₃Q₂Q₁Q₀，可改为任意名称（含中文）
- **自动化简** — 0-1 整数规划覆盖算法（见下方算法说明），最简与或表达式
- **手动圈选** — 拖拽画圈，自动识别有效矩形（含边缘环绕）
- **KaTeX 渲染** — 表达式数学排版，NOT 为上横线（over line）
- **表达式编辑** — 直接编辑表达式，提供变量 / NOT / AND / OR / 括号输入按钮

## 快速开始

```bash
cd k-map
npm install
npm start
```

- 本机：`http://localhost:3000`
- 局域网：终端显示的 Network 地址


## 自动化简算法

### 1. 算法目标

用户在卡诺图格子中设置三种状态：**1**（必须覆盖）、**0**（不可覆盖）、**X**（无关项，可覆盖也可不覆盖）。算法的最终目标是得到最简与或表达式。

主目标为 min Σ xᵢ，其中 xᵢ 表示第 i 个合法圈是否被选中（1=选中，0=不选）。该目标表示 **项数最少**。

### 2. 基本定义

设卡诺图中共有 M 个 1 格。枚举出的所有合法圈为 C₁, C₂, …, Cₙ。决策变量 xᵢ ∈ {0,1}，每个被选中的圈对应最终表达式中的一个乘积项。

### 3. 合法圈枚举

合法圈必须满足：形状为矩形；面积为 2ᵏ（1, 2, 4, 8, 16, …）；可跨越边界；圈内只能含 1 或 X；不能含 0；至少含一个 1。非法圈不会进入后续优化模型。

### 4. 合法圈信息记录

对每个合法圈 Cᵢ 记录：cellsᵢ（覆盖的全部格子，含 1 和 X）、onesᵢ（覆盖的所有 1 格）、Sᵢ（面积）、Lᵢ（文字数）。

若卡诺图有 n 个变量，圈面积为 Sᵢ，则文字数 Lᵢ = n − log₂ Sᵢ。例如 n=4：面积 1→4 文字、2→3、4→2、8→1、16→0。

### 5. 覆盖矩阵构造

设第 j 个 1 格为 mⱼ（j = 1, 2, …, M）。定义覆盖矩阵 A：

aⱼᵢ = 1 表示 Cᵢ 覆盖 mⱼ，否则为 0。实现中使用 BigInt 位掩码加速。

### 6. 基本覆盖约束

每个 1 格必须至少被一个选中的圈覆盖：Σ aⱼᵢ xᵢ ≥ 1（对每个 j）。

### 7. 主优化模型

```
min  Σ xᵢ
s.t. Σ aⱼᵢ xᵢ ≥ 1    (j = 1, 2, …, M)
     xᵢ ∈ {0, 1}      (i = 1, 2, …, N)
```

在所有能够覆盖全部 1 格的圈组合中，选择圈数最少的组合。求解得到最少项数 Tₘᵢₙ = min Σ xᵢ。

### 8. 固定最少项数

加入约束 Σ xᵢ = Tₘᵢₙ，后续所有优化都必须在项数最少的前提下进行。

### 9. 大圈优先规则

大圈优先不作为主目标。算法只在项数已经最少的解中优先选择更大的圈。在固定项数最少的前提下，最小化总文字数：

```
min  Σ Lᵢ xᵢ
s.t. Σ aⱼᵢ xᵢ ≥ 1
     Σ xᵢ = Tₘᵢₙ
     xᵢ ∈ {0, 1}
```

保证：项数不增加；优先大圈；不产生冗余项。

### 10. 冗余圈排除规则

若一个被选中的圈删除后所有 1 格仍能被其他已选圈覆盖，则该圈为冗余圈。设选中集合为 S，若存在 Cₖ ∈ S 满足删除 Cₖ 后其余圈的 ones 并集仍等于全部 ones 并集，则删除 Cₖ。

### 11. 最终选择规则

优先级：覆盖所有 1 → 项数最少 → 总文字数最少 → 去除冗余圈。

### 12. 圈到逻辑项的转换

将选中圈覆盖的最小项转为二进制，逐位比较：全 0 → 保留反变量；全 1 → 保留原变量；既有 0 又有 1 → 消去。例如 4 变量圈覆盖 0011, 0111, 1011, 1111 → 第 1、2 位消去，第 3、4 位保留 → CD。

### 13. 最终表达式生成

设选中圈集合为 {Cₚ₁, …, Cₚₜ}，每个圈生成乘积项 Pₖ，最终 F = P₁ + P₂ + … + Pₜ，其中 t = Tₘᵢₙ。

### 14. 完整算法流程

```
输入卡诺图状态 (0/1/X)
  ↓
提取所有 1 格和 X 格
  ↓
枚举所有合法圈
  ↓
删除非法圈和重复圈
  ↓
构造覆盖矩阵 A
  ↓
以项数最少为主目标求解
  ↓
得到最少项数 Tₘᵢₙ
  ↓
加入约束 Σ xᵢ = Tₘᵢₙ
  ↓
最小化总文字数
  ↓
检查并删除冗余圈
  ↓
圈 → 逻辑乘积项
  ↓
输出最简与或表达式
```

### 15. 算法本质

基于卡诺图合法圈枚举的 **0-1 整数规划覆盖算法**。核心模型：min Σ xᵢ，约束 Σ aⱼᵢ xᵢ ≥ 1，xᵢ ∈ {0,1}。求得最少项数后，通过 min Σ Lᵢ xᵢ 实现大圈优先。
